FORGEPLAY 라이선스 안내

열린 코드는 열려 있게. 다른 권리는 분명하게.

ForgePlay는 여러 라이선스가 함께 적용되는 배포물이다. 아래 내용은 이해를 돕기 위한 안내이며, 실제 권리와 의무는 라이선스 매니페스트와 정확한 적용 범위 문서, 각 제3자 라이선스가 정한다.

정식 라이선스 파일 받기
01 / 권리

GPLv3를 지키면 별도 허락이 필요 없다

적용 범위 문서가 ForgePlay Game Mode로 지정한 코드는 GPL-3.0-only를 따른다. GPLv3 조건을 지키면 별도 허락 없이 사용·연구·수정·재배포하거나 상업적으로 이용할 수 있다.

02 / 의무

배포할 때는 소스와 권리까지 제공한다

대상 코드나 이를 포함한 결합물을 배포할 때는 필요한 고지를 보존하고 수정 사실을 밝히며, GPLv3가 요구하는 대응 소스와 빌드·패키징 자료를 함께 제공해야 한다.

03 / 범위

지정 범위는 좁지만, 결합된 실행 파일에는 더 넓은 의무가 따른다

Game Mode 전용 코드와 지정된 혼합 파일 부분, GameModeProcessHost, 두 Wine 패치가 직접 대상이다. 저장소 전체를 일괄 재라이선스하지는 않지만, 현재 앱처럼 대상 코드를 하나의 실행 파일에 결합해 배포하면 그 결합물에 필요한 GPLv3 권리와 대응 소스를 제공해야 한다.

04 / 제3자

구성 요소마다 적용 조건이 다르다

변경하지 않은 Wine 자료는 적용되는 LGPL 권리를 유지한다. D3DMetal과 다른 렌더러, 글꼴, 아트워크, 상표에는 각각의 조건이 적용되며, D3DMetal은 Apple의 조건에 따라 별도 구성 요소로 배포된다.

05 / 릴리스

바이너리와 소스는 같은 시점에 공개한다

적용 대상인 목적 코드를 담은 GitHub Release에는 버전이 맞는 대응 소스와 필요한 고지를 동시에 올린다. 바이너리를 먼저 공개한 뒤 소스를 나중에 덧붙이는 방식은 사용하지 않는다.

공식 저장소는 현재 외부 코드 기여를 받지 않는다. 이는 유지보수 정책일 뿐이며, 적용 라이선스가 허용하는 포크·수정·재배포 권리를 제한하지 않는다. 수정본을 공식 ForgePlay 릴리스처럼 표시할 수 없으며, 라이선스는 ForgePlay 이름·로고·아트워크의 사용권을 주지 않는다.
