FORGEPLAY 라이선스, 쉽게 보기

게임 모드 코드는 GPLv3로 공개합니다. 나머지 구성 요소는 각자의 조건을 따릅니다.

ForgePlay는 구성 요소별로 다른 라이선스를 따릅니다. 적용 범위 문서에 명시된 게임 모드 코드는 GPL-3.0-only이며, Wine·D3DMetal을 비롯한 제3자 구성 요소에는 각자의 조건이 적용됩니다. 이 페이지는 핵심만 풀어쓴 안내이고, 실제 권리와 의무는 아래 공식 문서가 정합니다.

공식 라이선스 문서 보기
01 / 할 수 있는 것

GPLv3를 따르면 누구나 사용할 수 있습니다

적용 범위 문서가 ForgePlay 게임 모드 코드로 지정한 부분은 GPL-3.0-only를 따릅니다. GPLv3 조건을 지키면 별도 허락 없이 사용·연구·수정·재배포하거나 상업적으로 이용할 수 있습니다.

02 / 지켜야 할 것

배포할 때는 소스와 권리도 함께 제공해야 합니다

대상 코드나 이를 포함한 결합물을 배포할 때는 필요한 고지를 보존하고 수정 사실을 밝혀야 합니다. GPLv3가 요구하는 대응 소스와 빌드·패키징 자료도 함께 제공해야 합니다.

03 / 적용 범위

직접 지정된 코드는 일부지만, 결합 배포물의 의무는 더 넓을 수 있습니다

게임 모드 전용 코드와 지정된 혼합 파일 부분, GameModeProcessHost, 두 Wine 패치가 직접 대상입니다. 저장소 전체를 하나의 라이선스로 바꾸는 것은 아니지만, 현재 앱처럼 대상 코드를 하나의 실행 파일에 결합해 배포하면 그 결합물에 필요한 GPLv3 권리와 대응 소스를 제공해야 합니다.

04 / 제3자 구성 요소

구성 요소마다 각자의 라이선스를 따릅니다

수정하지 않은 Wine 자료에는 해당 LGPL 조건이 유지됩니다. D3DMetal과 다른 렌더러, 글꼴, 아트워크, 상표에는 각각의 조건이 적용되며, D3DMetal은 Apple의 조건에 따라 별도 구성 요소로 배포됩니다.

05 / ForgePlay 릴리스

바이너리와 일치하는 소스를 동시에 공개합니다

적용 대상인 목적 코드를 담은 GitHub Release에는 버전이 일치하는 대응 소스와 필요한 고지를 동시에 올립니다. 바이너리를 먼저 공개한 뒤 소스를 나중에 덧붙이는 방식은 사용하지 않습니다.

공식 저장소는 현재 외부 코드 기여를 받지 않습니다. 하지만 이는 프로젝트 운영 방침일 뿐, GPLv3가 허용하는 포크·수정·재배포 권리를 제한하지 않습니다. 수정판은 공식 ForgePlay 릴리스로 오인되게 표시할 수 없으며, ForgePlay의 이름·로고·아트워크에는 별도의 권리가 적용됩니다.
