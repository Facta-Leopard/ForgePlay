02 / A SECOND WORLD FIRST*

DLSS5 Emulation

ForgePlay 2.0.0 DLSS5 Emulation · Beta
Scope & evidence ↗

ForgePlay applies neural visual enhancement to completed RGB frames of Windows games running on Mac. It uses publicly available HyPER-GAN weights to approximate a DLSS 5-like appearance—not NVIDIA DLSS code or weights.

The contribution is the integration into the Windows-game execution and presentation path on Mac—not the invention of HyPER-GAN or a port of NVIDIA DLSS 5.

In 2.0.0, DLSS5 Emulation and frame generation can run together and be switched independently. Both default to off in new configurations; saved choices are preserved. Performance varies by game, resolution, and settings.

02 / DLSS5 Emulation — scope, timeline, and sources+

What “world first” means here

The developer’s claim concerns real-time integration of HyPER-GAN-based photorealistic post-processing into completed frames of Windows games running on macOS, without NVIDIA DLSS code or weights. The public-source review dated 27 September 2026 found no earlier implementation within that scope. It does not certify every unpublished or unindexed implementation worldwide.

19 September is the MVP results publication date. 27 September is the prior-work review date. Neither is an inferred date for the original idea or the precise end of MVP testing.

Related work and the scope of comparison

Photorealistic enhancement and HyPER-GAN integration already exist in other contexts. The claim is narrower: their integration into Windows games running on macOS. The following original sources should be read within their own scope.

HyPER-GAN ↗
The original model and pretrained weights, with CARLA real-time inference and Unreal Engine integration instructions. ForgePlay does not claim to have invented the model or its first real-time use.
CARLA2Real ↗ / Hybrid-Sim2Real ↗
Photorealism enhancement for CARLA simulation and game-engine synthetic datasets. This is a different application scope from integrating post-processing into Windows games on Mac.
EndoLive ↗
An endoscopic style-transfer project using ConStructS and HyPER-GAN that reports operation on Apple Vision Pro. It is not a Windows-game integration, and shows why “first HyPER-GAN use on Apple hardware” would be too broad a claim.

The supplied fork comparisons were also checked. On 27 September 2026, lastquest/main was identical to upstream/main; porom004/main was five commits behind with no ahead commits. These comparisons alone neither prove nor disprove worldwide priority.
