지원 안내 한국어

지원이 필요하면 ForgePlay GitHub Issues에 문의해 주세요. 게임 이름, Steam App ID와 빌드 ID, macOS 버전, 최근 실행 결과와 오류 메시지를 적어 주세요. 진단 자료에는 ForgePlay 런타임의 식별 정보와 빌드 지문, 그래픽 백엔드의 실행 경로와 로드 기록, 선택한 프리픽스 정보를 함께 첨부해 주세요.

  • 문제 진단 화면에서 지원 번들을 만들 수 있으면 먼저 생성하고, 공유하기 전에 파일 내용을 직접 검토하세요.
  • 지원 번들에는 최근 실행 로그, 선택한 진단 결과, 프리픽스 메타데이터, 호환성 정보, 건너뛴 파일 목록, 앱 상태 요약이 포함될 수 있습니다.
  • Steam 비밀번호, Steam Guard 코드, 결제 정보, Apple ID 로그인 정보, 비공개 키, 관련 없는 개인 파일은 보내지 마세요.
  • 웹에서 직접 배포하는 DMG에 포함된 D3DMetal은 Apple의 고지와 별도 조건이 적용되는 제3자 구성 요소입니다. Steam, Microsoft 런타임, DirectX, NVIDIA PhysX, OpenAL, XNA 설치 파일은 포함하지 않으므로 각 공식 공급처에서 받은 파일을 사용하세요.

Support Guide English

For help, open an issue in the ForgePlay GitHub repository. Include the game name, Steam App ID and build ID, macOS version, latest launch result, and any error message. Attach diagnostic details for the bundled ForgePlay runtime, including its identity and build fingerprint, the renderer’s launch path and loading records, and the selected prefix.

  • If ForgePlay offers a support bundle in Diagnostics, create it first and review the files before sharing.
  • A support bundle may include recent launch logs, selected diagnostics, prefix metadata, compatibility information, lists of skipped files, and app status summaries.
  • Do not send Steam passwords, Steam Guard codes, payment details, Apple ID credentials, private keys, or unrelated personal files.
  • D3DMetal in the direct-distribution DMG is a separately identified third-party component under Apple notices and terms. Steam, Microsoft Runtime, DirectX, NVIDIA PhysX, OpenAL, and XNA installers are not included; use files from official vendors.

Guía de soporte Español

Si necesitas ayuda, abre una incidencia en el repositorio de ForgePlay en GitHub. Incluye el nombre del juego, sus ID de aplicación y compilación en Steam, la versión de macOS, el último resultado de inicio y cualquier mensaje de error. Adjunta también datos de diagnóstico: la identificación y huella de compilación de ForgePlay Runtime, la ruta de ejecución y los registros de carga del renderizador, y el prefijo seleccionado.

  • Si ForgePlay ofrece un paquete de soporte en Diagnósticos, créalo primero y revisa los archivos antes de compartirlos.
  • El paquete puede incluir registros recientes, diagnósticos seleccionados, metadatos del prefijo, información de compatibilidad, listas de archivos omitidos y resúmenes de estado de la app.
  • No envíes contraseñas de Steam, códigos de Steam Guard, datos de pago, credenciales de Apple ID, claves privadas ni archivos personales no relacionados.
  • D3DMetal en el DMG de distribución directa es un componente de terceros identificado por separado y sujeto a los avisos y términos de Apple. No se incluyen instaladores de Steam, Microsoft Runtime, DirectX, NVIDIA PhysX, OpenAL ni XNA; usa archivos de proveedores oficiales.

支持指南 简体中文

如需帮助，请在 ForgePlay 的 GitHub 仓库中提交问题。请注明游戏名称、Steam App ID 和构建 ID、macOS 版本、最近的启动结果及错误信息。同时附上诊断资料，包括内置 ForgePlay Runtime 的标识与构建指纹、渲染器的执行路径与加载记录，以及所选前缀的信息。

  • 请不要发送 Steam 密码、Steam Guard 代码、付款信息、Apple ID 登录信息、私钥或无关的个人文件。

Guide d'assistance Français

Pour obtenir de l’aide, ouvrez un ticket dans le dépôt GitHub de ForgePlay. Indiquez le jeu, ses identifiants d’application et de build Steam, la version de macOS, le dernier résultat de lancement et les messages d’erreur. Joignez également les informations de diagnostic : identification et empreinte de build de ForgePlay Runtime, chemin d’exécution et journaux de chargement du moteur de rendu, ainsi que le préfixe sélectionné.

  • Si ForgePlay propose un paquet d’assistance dans Diagnostics, créez-le d'abord et vérifiez les fichiers avant de les partager.
  • Un paquet d’assistance peut contenir des journaux récents, diagnostics sélectionnés, métadonnées du préfixe, informations de compatibilité, listes de fichiers ignorés et résumés d'état de l'app.
  • N'envoyez pas de mots de passe Steam, codes Steam Guard, données de paiement, identifiants Apple ID, clés privées ni fichiers personnels sans rapport.
  • D3DMetal dans le DMG distribué directement est un composant tiers identifié séparément, soumis aux avis et conditions d’Apple. Les installateurs Steam, Microsoft Runtime, DirectX, NVIDIA PhysX, OpenAL et XNA ne sont pas inclus ; utilisez les fichiers des fournisseurs officiels.
