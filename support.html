지원 안내 한국어

지원 요청은 ForgePlay GitHub Issues에 남겨주세요. 게임 이름, Steam App ID와 빌드 ID, macOS 버전, 앱에 포함된 ForgePlay Runtime의 식별 정보와 빌드 지문, 렌더러 경로와 로드 기록, 선택한 Prefix, 최근 실행 결과, 화면에 표시된 오류 메시지를 함께 적어주세요.

  • 문제 진단 화면에서 지원 번들을 만들 수 있으면 먼저 생성하고, 공유하기 전에 파일 내용을 직접 검토하세요.
  • 지원 번들에는 최근 실행 로그, 선택한 진단 결과, Prefix 메타데이터, 호환성 정보, 건너뛴 파일 목록, 앱 상태 요약이 포함될 수 있습니다.
  • Steam 비밀번호, Steam Guard 코드, 결제 정보, Apple ID 자격 증명, 개인 키, 관계없는 개인 파일은 보내지 마세요.
  • 웹에서 직접 배포하는 DMG에 포함된 D3DMetal은 Apple의 고지와 별도 조건이 적용되는 제3자 구성 요소입니다. Steam, Microsoft Runtime, DirectX, NVIDIA PhysX, OpenAL, XNA 설치 파일은 포함하지 않으므로 각 공식 공급처에서 받은 파일을 사용하세요.

Support Guide English

Open a ForgePlay GitHub Issue for support. Include the game name and Steam App/build IDs, macOS version, bundled ForgePlay Runtime identity and build fingerprint, renderer route/load evidence, selected Prefix, recent launch result, and any visible error message.

  • If ForgePlay offers a support bundle in Diagnostics, create it first and review the files before sharing.
  • A support bundle may include recent launch logs, selected diagnostics, prefix metadata, compatibility information, skipped file manifests, and app status summaries.
  • Do not send Steam passwords, Steam Guard codes, payment details, Apple ID credentials, private keys, or unrelated personal files.
  • D3DMetal in the direct-distribution DMG is a separately identified third-party component under Apple notices and terms. Steam, Microsoft Runtime, DirectX, NVIDIA PhysX, OpenAL, and XNA installers are not included; use files from official vendors.

Guía de soporte Español

Para solicitar ayuda, abre una incidencia en GitHub Issues de ForgePlay. Incluye el nombre del juego y los identificadores de Steam App/build, la versión de macOS, la identidad y huella de compilación del ForgePlay Runtime incluido, las pruebas de route/load del renderizador, el Prefix seleccionado, el resultado reciente de inicio y cualquier error visible.

  • Si ForgePlay ofrece un paquete de soporte en Diagnósticos, créalo primero y revisa los archivos antes de compartirlos.
  • El paquete puede incluir registros recientes, diagnósticos seleccionados, metadatos de Prefix, información de compatibilidad, listas de archivos omitidos y resúmenes de estado de la app.
  • No envíes contraseñas de Steam, códigos de Steam Guard, datos de pago, credenciales de Apple ID, claves privadas ni archivos personales no relacionados.
  • D3DMetal en el DMG de distribución directa es un componente de terceros identificado por separado y sujeto a los avisos y términos de Apple. No se incluyen instaladores de Steam, Microsoft Runtime, DirectX, NVIDIA PhysX, OpenAL ni XNA; usa archivos de proveedores oficiales.

Support-Leitfaden Deutsch

Eröffne für Support eine Meldung in den ForgePlay GitHub Issues. Nenne Spielname und Steam App-/Build-ID, macOS-Version, Identität und Build-Fingerabdruck der enthaltenen ForgePlay Runtime, Renderer-route/load-Nachweise, ausgewählten Prefix, letztes Startergebnis und sichtbare Fehlermeldungen.

  • Wenn ForgePlay unter Diagnose ein Support-Paket anbietet, erstelle es zuerst und prüfe die Dateien vor dem Teilen.
  • Ein Support-Paket kann aktuelle Startlogs, ausgewählte Diagnosen, Prefix-Metadaten, Kompatibilitätsinformationen, Listen übersprungener Dateien und App-Status enthalten.
  • Sende keine Steam-Passwörter, Steam-Guard-Codes, Zahlungsdaten, Apple-ID-Zugangsdaten, privaten Schlüssel oder unbeteiligten persönlichen Dateien.
  • D3DMetal im direkt vertriebenen DMG ist eine separat gekennzeichnete Drittanbieterkomponente unter Apples Hinweisen und Bedingungen. Installer für Steam, Microsoft Runtime, DirectX, NVIDIA PhysX, OpenAL und XNA sind nicht enthalten; verwende Dateien offizieller Anbieter.

サポートガイド 日本語

サポート依頼は ForgePlay GitHub Issues に投稿してください。ゲーム名と Steam App／ビルド ID、macOS バージョン、同梱 ForgePlay Runtime の識別子とビルド指紋、レンダラーの route/load 証拠、選択した Prefix、直近の起動結果、表示されたエラーを記載してください。

  • 診断画面でサポートバンドルを作成できる場合は、先に作成し、共有前に内容を確認してください。
  • サポートバンドルには、最近の起動ログ、選択した診断、Prefix メタデータ、互換性情報、スキップされたファイル一覧、アプリ状態の概要が含まれることがあります。
  • Steam パスワード、Steam Guard コード、支払い情報、Apple ID 資格情報、秘密鍵、関係のない個人ファイルは送らないでください。
  • 直接配布 DMG の D3DMetal は、Apple の通知と条件が適用される、明確に区分された第三者コンポーネントです。Steam、Microsoft Runtime、DirectX、NVIDIA PhysX、OpenAL、XNA のインストーラは含まれません。公式提供元のファイルを使用してください。

支持指南 简体中文

如需支持，请在 ForgePlay GitHub Issues 中提交报告，并提供游戏名称和 Steam App／build ID、macOS 版本、内置 ForgePlay Runtime 的标识与构建指纹、渲染器 route/load 证据、所选 Prefix、最近的启动结果以及可见错误信息。

  • 如果 ForgePlay 在诊断页面提供支持包，请先创建，并在分享前检查文件内容。
  • 支持包可能包含最近的启动日志、所选诊断、Prefix 元数据、兼容性信息、跳过文件清单和应用状态摘要。
  • 请不要发送 Steam 密码、Steam Guard 代码、付款信息、Apple ID 凭据、私钥或无关的个人文件。
  • 直接分发 DMG 中的 D3DMetal 是单独标识的第三方组件，适用 Apple 的声明与条款。DMG 不包含 Steam、Microsoft Runtime、DirectX、NVIDIA PhysX、OpenAL 或 XNA 安装程序；请使用官方供应商提供的文件。

支援指南 繁體中文

如需支援，請在 ForgePlay GitHub Issues 中提交回報，並提供遊戲名稱和 Steam App／build ID、macOS 版本、內建 ForgePlay Runtime 的識別資訊與建置指紋、渲染器 route/load 證據、所選 Prefix、最近啟動結果，以及可見錯誤訊息。
