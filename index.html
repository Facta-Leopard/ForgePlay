See the difference

*To our knowledge, the first publicly documented open-source Windows gaming platform designed to carry a live Wine game session through a native macOS Game Mode-capable host, as of 28 July 2026.

WHAT IS macOS GAME MODE?

macOS gives the game priority. ForgePlay puts Windows games in that path.

Game Mode reduces background activity, prioritizes CPU and GPU access for the game, and lowers wireless input and audio latency.

CPU + GPU Highest-priority access
2× Bluetooth sampling rate
↓ Background activity
Windows game → ForgePlay Game Host → macOS Game Mode

ForgePlay’s Game Mode path is an opt-in beta. Run the game full screen and confirm activation in macOS Game Overlay.
