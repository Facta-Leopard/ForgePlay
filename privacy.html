Privacy Notice

ForgePlay keeps setup and diagnostics on your Mac. This notice explains what is stored, what is redacted, and what only leaves the device when you decide to share it.

No advertising tracking, third-party analytics, crash-reporting SDK, or remote telemetry SDK. AI diagnostics are opt-in and use Apple Foundation Models on this Mac.

ForgePlay는 사용자의 Mac에서 Windows 게임 프리픽스를 설정하고, 실행 문제를 진단하고, 사용자가 요청할 때 지원 번들을 만들기 위해 설계되었습니다. ForgePlay 앱에는 광고 추적, 제3자 분석, 크래시 리포팅 SDK, 원격 텔레메트리 SDK가 포함되어 있지 않습니다.

  • 설정 상태, 선택한 파일 경로, 보안 범위 북마크, 게임 기록, 프리픽스 메타데이터, 런타임 설치 기록, 실행 기록, 진단 기록, 호환성 기록은 사용자의 Application Support 폴더에 저장됩니다.
  • ForgePlay는 사용자가 선택한 게임 저장소, Steam 및 Windows 필수 구성 요소 설치 파일, 로그, 가져온 게임 폴더, 선택한 Apple Evaluation 환경 DMG 또는 redist에 접근할 수 있습니다. 사용자에게 외부 실행 엔진을 고르도록 요구하지 않으며, 배포 버전은 앱에 포함된 ForgePlay 런타임만 사용합니다. 접근 권한이 만료되면 해당 항목을 다시 선택해 달라고 요청합니다.

  • 지원 번들은 사용자가 요청할 때만 만들어집니다. 접근 토큰, API 키, 비밀번호, URL에 포함된 비밀값, Steam 식별자, 사용자 폴더 경로, 선택한 저장소와 게임 경로는 가능한 범위에서 가립니다.
  • ForgePlay는 Steam 비밀번호나 Steam Guard 코드를 요청, 저장, 전송하지 않습니다. Steam 로그인은 앱에 포함된 ForgePlay 런타임 안의 Steam 자체 UI에서 진행됩니다.

Privacy Notice English

ForgePlay is built for local Windows game setup, launch diagnostics, and user-requested support bundle creation on the user's Mac. The app does not include advertising tracking, third-party analytics, crash reporting SDKs, or remote telemetry SDKs.

  • Setup state, selected paths, security-scoped bookmarks, game records, prefix metadata, runtime installation records, launch records, diagnostics, and compatibility records are stored in the user's Application Support folder.
  • ForgePlay can access user-selected game storage, Steam installers, Windows prerequisite installers, logs, imported game folders, and an optional Apple Evaluation environment DMG or redist. It never asks the user to select an external execution engine; every distribution build uses only the bundled ForgePlay Runtime. If access expires, ForgePlay asks the user to select the item again.
  • AI diagnostics are off by default. When enabled, ForgePlay shows a redacted preview first and analyzes only with Apple Foundation Models on this Mac, without an external AI server or API key.
  • Support bundles are created only when the user requests them. ForgePlay redacts common secrets, Steam identifiers, home/user paths, and selected local storage or game paths where possible.
  • ForgePlay does not ask for, store, or transmit Steam passwords or Steam Guard codes. Steam login happens inside Steam's own UI through the bundled ForgePlay Runtime.

ForgePlay está diseñado para configurar prefijos locales de juegos de Windows en Mac, diagnosticar fallos de inicio y crear paquetes de soporte cuando el usuario lo solicita. La app no incluye seguimiento publicitario, analítica de terceros, SDK de informes de fallos ni telemetría remota.

  • El estado de configuración, rutas seleccionadas, marcadores con ámbito de seguridad, registros de juegos, metadatos de Prefix, instalaciones de Runtime, ejecuciones, diagnósticos y compatibilidad se guardan en Application Support del usuario.
  • ForgePlay accede solo a ubicaciones o archivos elegidos por el usuario: almacenamiento de juegos, instaladores de Steam o requisitos de Windows, registros, carpetas importadas y un DMG o redist opcional del entorno Apple Evaluation. Nunca solicita un motor de ejecución externo; todas las compilaciones usan únicamente ForgePlay Runtime incluido.
  • El diagnóstico con IA está desactivado de forma predeterminada. Si se activa, ForgePlay muestra primero una vista previa redactada y usa solo Apple Foundation Models en este Mac, sin servidor externo ni clave API.

  • Einrichtungsstatus, ausgewählte Pfade, Security-Scoped Bookmarks, Spieleinträge, Prefix-Metadaten, Runtime-Installationen, Startprotokolle, Diagnosen und Kompatibilitätsdaten werden im Application-Support-Ordner des Nutzers gespeichert.
