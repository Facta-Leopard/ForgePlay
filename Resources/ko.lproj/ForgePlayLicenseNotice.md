# ForgePlay 라이선스 및 법무 안내

이 문서는 ForgePlay에 포함된 법무 자료를 한국어로 이해하기 위한 안내문입니다. 앱에 동봉된 정식 라이선스 전문, 저작권 고지 및 각 구성요소의 개별 조건을 대체하지 않습니다.

## 릴리스 식별 정보

ForgePlay 공식 빌드는 `ForgePlay` 표시 이름, `Info.plist`의 번들 식별자·버전·빌드 번호, Developer ID 서명, 그리고 DMG와 함께 배포되는 체크섬 및 릴리스 매니페스트로 식별합니다. 수정본은 수정 사실을 표시해야 하며 공식 ForgePlay 릴리스라고 주장하거나 관리자의 보증을 암시해서는 안 됩니다.

## ForgePlay Game Mode

적용 범위 문서가 식별한 ForgePlay Game Mode 코드는 GNU General Public License version 3 only(`GPL-3.0-only`)로 배포됩니다. 정확한 적용 범위와 추가 조건은 `LICENSES/ForgePlayGameMode/GAME_MODE_LICENSE_SCOPE.md`에 기록되어 있습니다.

ForgePlay Game Mode  
Copyright (C) 2026 Facta-Leopard  
Original source: https://github.com/Facta-Leopard/ForgePlay

수정하지 않은 라이선스 전문은 `LICENSES/GPL-3.0-only.txt`와 `LICENSES/LGPL-2.1-or-later.txt`로 포함됩니다. 저장소 전체의 라이선스 경계는 `LICENSE.md`에서 확인할 수 있습니다.

## ForgePlay Frame Generation

적용 범위 문서가 식별하는 ForgePlay 자체 작성 Frame Generation 코드에는 GNU 일반 공중 사용 허가서 버전 3만(`GPL-3.0-only`) 적용됩니다. 정확한 적용 범위, 소스 식별 정보 및 추가 조건은 동봉된 `LICENSES/ForgePlayFrameGeneration/FRAME_GENERATION_LICENSE_SCOPE.md`에 기록되어 있으며, 같은 디렉터리에 한국어 범위 안내, 고지문 및 파일·심볼 명세가 있습니다.

```text
ForgePlay Frame Generation
Copyright (C) 2026 Facta-Leopard
Original source: https://github.com/Facta-Leopard/ForgePlay
```

Wine에서 파생된 Frame Generation 로딩·환경 연동 코드는 별도로 식별된 `LGPL-2.1-or-later` 범위를 유지하며, 이번 Frame Generation GPL 지정으로 전환되지 않습니다. 이러한 소스 경계가 배포되는 결합 저작물의 GPL 의무를 없애지는 않습니다. D3DMetal·MetalFX를 비롯한 Apple 구성요소와 기타 제3자 구성요소에는 각자의 조건이 적용되며, 이 고지는 링크 예외를 부여하지 않습니다.

## 제3자 구성요소

Wine, 글꼴, 렌더러, Apple 기술 및 기타 제3자 구성요소에는 각자의 라이선스와 조건이 적용됩니다. ForgePlay는 해당 구성요소의 소유권을 주장하지 않습니다. 직접 배포 DMG에는 별도로 식별된 Apple 구성요소인 D3DMetal이 포함될 수 있으며, Apple 라이선스·승인 고지·원본 서명은 해당 페이로드와 함께 유지됩니다.

## Noto 글꼴 대체 지원

ForgePlay는 네이티브 앱 UI의 글꼴 대체 지원을 위해 수정하지 않은 Noto Sans 및 Noto Sans CJK 파일을 SIL Open Font License 1.1 조건으로 포함합니다. 라이선스 전문은 `NotoSans-OFL.txt`와 `NotoSansCJK-OFL.txt`로 동봉됩니다. 글꼴의 권리는 각 저작권자에게 있으며 ForgePlay는 소유권을 주장하지 않습니다. 앱 UI 언어를 Windows 프리픽스의 글꼴 정책으로 암묵적으로 사용하지도 않습니다.

Noto Sans: Copyright 2022 The Noto Project Authors (https://github.com/notofonts/latin-greek-cyrillic).

Noto Sans CJK: © 2014-2021 Adobe (http://www.adobe.com/).

앱의 법무 섹션에서 `Noto Sans OFL 1.1` 및 `Noto Sans CJK OFL 1.1` 버튼을 누르면 수정하지 않은 라이선스 전문을 열 수 있습니다.

## Nanum Gothic 런타임 글꼴 대체 지원

ForgePlay Runtime은 Windows 응용 프로그램의 한글 대체 글꼴로 수정하지 않은 Nanum Gothic Regular와 Bold를 포함합니다. Nanum Gothic: Copyright (c) 2010, NHN Corporation (http://www.nhncorp.com). 이 글꼴에는 ForgePlay Frame Generation의 GPL 지정이 아닌 SIL Open Font License 1.1이 적용됩니다. 같은 법무 섹션의 `Nanum Gothic OFL 1.1` 버튼에서 수정하지 않은 라이선스 전문과 예약 글꼴 이름을 확인할 수 있습니다(앱 리소스의 `Runners/ForgePlayRuntime/Legal/NanumGothic/OFL.txt`).

## 개인정보와 지원

ForgePlay는 Steam 비밀번호나 Steam Guard 코드를 요청하거나 저장하지 않습니다. 지원 번들은 사용자가 요청할 때만 로컬에서 만들며 공유 전에 직접 검토해야 합니다. 자세한 개인정보 고지, 지원 안내 및 외부 구성요소 고지는 같은 법무 섹션에서 열 수 있습니다.
